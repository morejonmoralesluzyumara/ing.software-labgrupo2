# Helarte Deli – Landing page (SIS324)

Sitio estático: HTML + CSS + JS (sin instalar nada).

## Ver en tu computadora
Abre la carpeta en Antigravity IDE y abre `index.html` en el navegador
(o usa la extensión Live Server).

## Subir a GitHub
```
git init
git add .
git commit -m "Landing Helarte Deli"
git branch -M main
git remote add origin https://github.com/TU_USUARIO/helarte-deli.git
git push -u origin main
```

## Publicar en Render
1. New + → **Static Site** → conecta tu repositorio.
2. Build Command: (déjalo vacío)
3. Publish Directory: `.`
4. Create Static Site.
